## Design notes
- Part A uses Chen notation. Every primary entity has directly connected attribute ovals; cross-page references are dashed rectangles without attributes.
- Key, composite, multivalued, derived and partial-key attributes are visually distinguished. Identifying relationships use double diamonds.
- Part B includes NN/NULL, PK, FK, UQ, DF and CK tags. Same-page foreign keys use arrows to target primary-key columns; cross-page references use dashed target boxes.
- M:N relationships with relationship attributes are represented as Chen diamonds in Part A and mapped to junction tables in Part B.
- Unconfirmed modeling choices are listed on `3-Questions-Assumptions`.
